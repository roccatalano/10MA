Simultaneous equations using elimination

Cambridge pp. 66–69
Learning intentions
  • To be able to identify and form equations involving a matching pair of terms
  • To be able to use the process of elimination to solve simultaneous equations
Key definitions
  • The elimination method for the solution of simultaneous equations is commonly used when the equations are written in the same form. One pronumeral is eliminated using addition or subtraction and the value of the other pronumeral can then be found using one of the original equations.
  • The method of elimination is generally used when both equations are in the form ax+by=d.
  • When there is no matching pair (as in the second example below) one or both of the equations can be multiplied by a chosen factor.
