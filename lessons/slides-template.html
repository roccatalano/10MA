Example 1

Collecting like terms

1A Review of algebra

Simplify by collecting like terms.

Key idea
Like terms have the same pronumeral part and, using addition and subtraction, can be collected to form a single term.
$3x - 7x + x = -3x$   $6a^2b - ba^2 = 5a^2b$
Note that $a^2b = ba^2$
a$7a + 3a$
$= \boldsymbol{10a}$
b$3a^2b - 2a^2b$
$= \boldsymbol{a^2b}$
c$5xy + 2xy^2 - 2xy + 3y^2x$
$= \boldsymbol{3xy + 5xy^2}$
