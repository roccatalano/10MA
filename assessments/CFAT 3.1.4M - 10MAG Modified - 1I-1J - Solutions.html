Question 1 1I.1 · L0   2 marks
Solve the following pair of simultaneous equations by using substitution.
$\begin{aligned}5x + y = 5\\y = 1 - x\end{aligned}$
$5x + (1 - x) = 5$
$4x = 4$, $x = 1$
$y = 1 - 1 = 0$
Cambridge Essential Mathematics 9 (3rd Ed), Exercise 2I Q2c (p. 141); adapted: stem reworded for a single part
Question 2 1I.1 · L0   2 marks
Solve the following pair of simultaneous equations by using substitution.
$\begin{aligned}3x - y = 7\\y = x + 5\end{aligned}$
$3x - (x + 5) = 7$
$2x = 12$, $x = 6$
$y = 6 + 5 = 11$
Cambridge Essential Mathematics 9 (3rd Ed), Exercise 2I Q3a (p. 141); adapted: stem reworded for a single part
Question 3 1J.1 · L0   2 marks
Solve these simultaneous equations by first adding the equations.
$\begin{aligned}4x + 3y = 5\\-4x - 5y = -3\end{aligned}$
Add: $-2y = 2$, $y = -1$
$4x - 3 = 5$, $x = 2$
Cambridge Essential Mathematics 9 (3rd Ed), Exercise 2J Q1c (p. 149); adapted: stem reworded for a single part
Question 4 1J.1 · L0   2 marks
Solve these simultaneous equations by first subtracting the equations.
$\begin{aligned}2x + 7y = 9\\2x + 5y = 11\end{aligned}$
Subtract: $2y = -2$, $y = -1$
$2x - 7 = 9$, $x = 8$

Question 5 1J.2 · L0   2 marks
Solve the following pair of simultaneous linear equations by using elimination.
$\begin{aligned}-x + 4y = 2\\3x - 8y = -2\end{aligned}$
$2 \times [1]$: $-2x + 8y = 4$
Add: $x = 2$
$-2 + 4y = 2$, $y = 1$
Cambridge Essential Mathematics 9 (3rd Ed), Exercise 2J Q3c (p. 149); adapted: stem reworded for a single part
Question 6 1J.2 · L0   2 marks
Solve the following pair of simultaneous linear equations by using elimination.
$\begin{aligned}3x + 2y = 0\\4x + y = -5\end{aligned}$
$2 \times [2]$: $8x + 2y = -10$
Subtract: $5x = -10$, $x = -2$
$-8 + y = -5$, $y = 3$
Cambridge Essential Mathematics 9 (3rd Ed), Exercise 2J Q3d (p. 149); adapted: stem reworded for a single part
